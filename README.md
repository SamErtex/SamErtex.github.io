POLÍTICA DE PRIVACIDADE — OPA - Auto Atendimento
Versão: 4.3.1

1. Objetivo

A extensão OPA - Auto Atendimento foi desenvolvida para automatizar tarefas de atendimento dentro do sistema de suporte da IXCSoft, no domínio https://suporte.ixcsoft.com.br/.

2. Dados processados

A extensão pode processar, exclusivamente para executar suas funções, informações que já estão disponíveis para o usuário autenticado no sistema de suporte, incluindo:

- identificador e protocolo do atendimento;
- departamento/fila do atendimento;
- status do atendimento;
- informações necessárias para identificar o usuário atendente;
- informações de tempo de permanência na fila;
- eventos de assunção, transferência e mensagens necessários para controlar o fluxo automático.

A extensão não solicita dados pessoais diretamente ao usuário e não possui formulário próprio para coleta de dados pessoais.

3. Finalidade do processamento

Os dados são utilizados somente para:

- identificar atendimentos elegíveis;
- assumir automaticamente atendimentos conforme as configurações escolhidas;
- marcar o atendimento como “Aguardando resposta do cliente”;
- acompanhar temporariamente a comunicação após a assunção;
- cancelar o monitoramento quando houver comunicação ou transferência;
- gerar notificações locais relacionadas ao atendimento.

4. Armazenamento

As configurações da extensão e os registros temporários necessários ao monitoramento são armazenados localmente por meio do armazenamento do Chrome.

Os registros temporários são removidos quando o monitoramento é encerrado, quando ocorre uma transferência ou após a conclusão da verificação de ausência de comunicação.

A extensão não mantém um banco de dados próprio na nuvem para armazenar atendimentos.

5. Compartilhamento e transmissão

A extensão não vende, aluga ou compartilha dados de atendimento com terceiros para publicidade ou marketing.

A extensão não possui servidor próprio para coleta de dados.

Quando uma ação automática é executada no sistema de suporte, a comunicação necessária ocorre com o próprio sistema de suporte da IXCSoft, utilizando a sessão já autenticada do usuário. Isso inclui ações como assumir um atendimento e marcar o atendimento como “Aguardando resposta do cliente”.

6. Mensagens e conteúdo dos atendimentos

A extensão observa eventos do sistema necessários para determinar se o atendente se comunicou com o cliente e para controlar o monitoramento de cinco minutos. O conteúdo das mensagens não é enviado para servidores próprios da extensão.

7. Notificações

As notificações do Chrome são utilizadas somente para informar eventos relacionados ao funcionamento da automação, como assunção de atendimento e ausência de comunicação durante o período configurado.

8. Segurança

A extensão utiliza as APIs de armazenamento, notificações e alarmes do Chrome somente para as funções necessárias ao seu funcionamento. As permissões declaradas no manifesto são limitadas às funcionalidades utilizadas pela extensão.

9. Controle pelo usuário

O usuário pode ativar ou desativar os modos de automação disponibilizados pela extensão e pode remover a extensão do Chrome a qualquer momento.

10. Alterações desta política

Esta política poderá ser atualizada quando houver alteração relevante no funcionamento da extensão, nas formas de processamento de dados ou nas exigências aplicáveis à publicação da extensão.

11. Contato

Questões sobre esta política ou sobre o tratamento de dados pela extensão devem ser direcionadas ao responsável pela disponibilização e administração da extensão.
